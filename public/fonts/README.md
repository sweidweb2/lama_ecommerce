# Web fonts

The site uses **Bagina** as the main font.

To enable it, add the font file here with one of these names:

- **Bagina-Regular.ttf**, or  
- **Bagina-Regular.woff2**

Download Bagina from e.g. [CDNFonts](https://www.cdnfonts.com/bagina.font) or [BeFonts](https://befonts.com/bagina-font.html) (check license for your use). Until the file is present, the browser will use the fallback system font.
