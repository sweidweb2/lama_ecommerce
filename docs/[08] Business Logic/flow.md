## Guest (Not Logged In)
- Browse home / catalog / search / product pages
- Add to cart / update cart / checkout (place order)
- Wishlist add/remove
- View order details (guest order path)
- Sign up / log in
- Contact us submit
- Newsletter / lead signup
- Read static pages (about, terms, privacy, shipping terms)

## User (User / Customer)
- All guest capabilities (with logged-in cart merge on login)
- Account: profile, change password, manage addresses
- Profile / settings
- Wishlist (account + public)
- Place order with saved addresses / save address after checkout
- View own orders & order details
- Write product reviews
- Log out (idle timeout)

## Admin (Admin)
- All storefront user capabilities
- Admin dashboard
- Catalog: products (CRUD, variants, images, grid), categories, brands, product views
- Sales: orders (view/edit/status/payment/shipment), carts (view/manage/checkout), shipping zones, promo codes
- Customers: users, leads, contact messages
- Engagement: reviews, Q&A
- Analytics
- Backups
- Log out (idle timeout); login/signup redirect into `/admin`
